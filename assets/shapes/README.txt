Aircraft top views used by XPTablet's Ground page
=================================================

aircraft_shapes.txt is made from AircraftShapesSVG by RexKramer1 and amnesica (the BelugaProject team):
    https://github.com/RexKramer1/AircraftShapesSVG
The drawings are licensed under the GNU General Public License v3.0 (LICENSE-GPL-3.0.txt in this folder).

XPTablet reads this file at run time; it is not part of the plugin's program. Its source is the SVG files above, also kept
in XPTablet's own repository (third_party/AircraftShapesSVG), together with the script that converts them
(tools/make_shapes.py): curves flattened to straight pieces, and each drawing resized to its type's published length and span.
Thank you to the authors for sharing them.
